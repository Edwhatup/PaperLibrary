长期以来，用强化学习训练大语言模型智能体，有一个绕不开的根本性难题：奖励信号太稀疏了。具体来说，智能体在一个环境里反复交互，走完十几步、几十步，最后才得到一个成功或失败的信号。问题是，这十几步里哪几步是真正关键的，哪几步是多余的甚至是有害的，从这个最终奖励里根本分不出来。这就是所谓的信用分配问题，而当交互轨迹越来越长、任务越来越复杂的时候，这个问题就变得越来越致命。

今天要聊的这篇论文，题目叫 AgentOPSD，全称是 Recursive Self-Distillation for Agentic Reinforcement Learning，来自清华大学、浙江大学和美团的联合团队。它想解决的正是这个问题：在不引入额外的价值网络、不增加额外采样开销的前提下，给长交互轨迹中的每一轮动作打出一个更有区分度的信用分。

先从现有方法的痛点说起。

目前最主流的无评论家强化学习方法是 GRPO，也就是 Group Relative Policy Optimization。它的思路很直接：对同一个任务采样一批轨迹，计算这批轨迹的平均奖励，然后把每条轨迹自身的奖励减去这个均值，得到一个优势值，再把这个优势值广播给轨迹里的每一个 token。这样做的好处是不需要训练价值函数，简洁高效。但坏处也很明显：整条轨迹里的每一个动作，不管关键不关键，都拿到了同一个优势分数。这相当于老师改卷子，不管你哪道题答得好、哪道题答错了，直接给整张卷子打一个总分，然后按总分奖惩每一道题。这种粗放式的信号，对短轨迹来说还勉强凑合，但轨迹一长，噪声就会盖过信号，训练效率大幅下降。

为了给每一步提供更密集的监督，另一个方向是在线蒸馏，其中一个分支叫做 OPSD，即 On-Policy Self-Distillation。它的做法是构造一个"教师"和一个"学生"。这两个角色共享同一套参数，区别在于教师在输入时多看到了一段特权信息，比如描述成功行为的技能说明，而学生只看到标准的交互历史。教师因为有了这个先验，对"正确行为"的建模能力更强，学生则通过向教师靠拢来提升自己。这种对比在 token 级别产生了一个差值，也就是对同一个 token，教师和学生各自赋予的对数概率之差，可以作为一个局部监督信号。

问题在于，当你把 OPSD 这个思路直接搬进多轮交互场景时，会遇到两个明显的错位。第一，token 级别的信号和智能体的交互节奏对不上。智能体每一轮产生一段完整的动作文本，然后环境响应一次，reward 的边界是轮次，不是单个 token。把 token 级别的蒸馏差值直接用来指导每个 token 的更新，等于把本来属于整个动作的功劳切碎分给了每个字，这不合理。第二，也是更根本的问题：现有方法，包括一个叫 StepOPSD 的工作，虽然已经意识到要在步骤级别聚合信号，但它对每一步的评价是孤立进行的，不考虑这一步之前已经发生了什么。假设前几轮的动作已经把任务推进得非常顺利，那第七轮即使产生了一个强烈的局部信号，它的实际贡献也可能很小，因为任务就算没有它也大概率成功了。反过来，在一个局势还很不明朗的时刻，一个中等强度的信号可能具有极大的转折意义。孤立地看每一步，就会错过这种历史依赖性。

AgentOPSD 的核心洞察可以用一句话来概括：一轮动作的信用，不应该由它自己的局部信号来决定，而应该由它的信号对"最终成功概率的估计"的改变幅度来决定。

这个洞察是通过贝叶斯框架来形式化的。我们来把这个直觉展开说清楚。

想象你在追踪一件事情成功的可能性。在轨迹开始之前，你根据这一批采样轨迹的平均成功率，对当前任务有一个初始的成功概率判断，比如说 40%。轨迹走到第一轮，智能体做了一个动作，这个动作在教师-学生对比下产生了一个差值，可以理解为"这个动作比较像成功轨迹里的行为"的程度。这个差值就是新的证据。贝叶斯更新的逻辑是：你把这个证据代入，重新计算"给定这个动作，任务最终成功的概率"应该变成多少。如果从 40% 上升到了 60%，说明这一轮动作很有价值。如果从 40% 变到了 41%，说明这一轮动作贡献不大。如果反而从 40% 下降到了 30%，说明这一轮动作是有害的。

这里有一个数学上很方便的处理：把概率转换成对数几率空间来做更新。所谓对数几率，就是 log(p/(1-p))，0.5 的概率对应对数几率是 0，概率越高对数几率越大，概率越低则越小。在对数几率空间里，贝叶斯更新变成了加法：新的对数几率等于旧的对数几率加上这一轮的证据值。这就把递归更新变成了一个简洁的累加过程。

AgentOPSD 的方法流程是这样的。首先，对于每一轮动作，把这一轮里所有 token 的教师-学生对数概率差值加总，得到一个轮次级别的证据值。这个加总操作，解决了 token 粒度和交互轮次粒度不对齐的问题，让信号边界和环境响应边界对齐。

其次，维护一个"信念状态"，也就是当前对最终成功概率的估计，以对数几率的形式存储。每一轮新的证据进来，就用带衰减的递归方式更新这个信念状态。衰减的意思是：比较久远的历史证据会随时间折旧，不会永久压制后来的更新。同时，衰减只作用于累积证据项，初始先验每一步都保留，保证轨迹始终有一个基准锚点。

第三步，每一轮动作的信用，定义为这一轮更新后的信念状态与更新前的差值，也就是信念的边际修正量。这个量是有符号的：如果这一轮动作让成功概率上升，修正量为正；让成功概率下降，修正量为负。论文特别强调，这个有符号的修正量要和最终的验证结果方向对齐：对于一条成功的轨迹，如果某轮动作让信念上升，那这种一致性应该得到奖励；对于一条失败的轨迹，如果某轮动作让信念下降，说明这一轮在正确预判坏的走向，同样具有一定的信息价值。

这个设计有一个非常重要的性质：它只改变 GRPO 优势的幅度，不改变符号。最终 token 的梯度方向仍然由 GRPO 的成功或失败判断决定，AgentOPSD 只是在这个方向上做幅度的精细调节，给更关键的轮次放大信号，给冗余的轮次减小信号。这样就不会破坏 GRPO 原来的优化方向，而是在其基础上增加了分辨率。

接下来还有一个有意思的细节：为什么需要"先验锚点"。每条轨迹开始时，信念状态的初始值被设为这一批采样轨迹的平均成功率转化成的对数几率。为什么不从零开始？因为不同任务的难度不同，有些任务这批轨迹里 80% 都成功了，有些只有 20% 成功。如果都从对数几率零点，也就是 50% 的成功概率出发，那对于一个简单任务，信念状态会在错误的基准上计算修正量，早期的轮次会被错误地判定为高度关键。而用实际的组平均成功率作为先验，就给了信念状态一个和任务难度相关的起点，使得早期轮次的修正量能在正确的参考尺度上被估计。

教师-学生对比的合理性，论文在附录里做了理论分析。核心假设有两条：第一，技能条件下的教师分支近似于成功条件下的行为分布；第二，当成功率比较低的时候，边际行为分布近似于失败条件下的分布。在这两个假设下，教师-学生的对数概率差近似于理想贝叶斯因子，后者正是度量一个动作对"成功 vs 失败"支持程度的理论量。即使假设不完全成立，论文证明这个对比量至少保持了"哪些轮次更支持成功"的排序关系，而 AgentOPSD 真正依赖的就是这个排序，并不需要它是精确的概率估计。

讲完方法，来看实验。

论文在三个环境上做了评测。ALFWorld 是一个文本化的家居任务环境，智能体通过纯文本指令操控虚拟家居空间，完成比如"把苹果从冰箱里拿出来放到桌子上"这样的具身任务，一共有六类子任务。这个环境的特点是交互轮次比较长，每条轨迹平均需要十几步甚至更多。WebShop 是模拟网购环境，智能体需要搜索商品、点击筛选、满足用户的多个约束条件完成购买，评估用两个指标：完成度得分和严格成功率。Search-QA 则是检索增强的问答任务，智能体需要多次发出搜索请求、阅读返回文档、汇总信息才能回答问题，覆盖单跳和多跳两类问题，共七个数据集。

模型用的是 Qwen2.5 的 3B 和 7B 两个规模，在 H800 GPU 上训练。技能库来自 SkillRL 项目，通过关键词匹配检索，只在训练阶段输入给教师分支，推理时完全不使用外部技能。

基线方法分三组。第一组是无训练的，包括原始基础模型和在推理时注入技能的版本。第二组是 GRPO 系列，包括标准 GRPO 和注入技能的变体。第三组是各种自蒸馏强化学习方法，包括 OPSD、GRPO+OPSD、Skill-SD、RLSD、SDAR 和 StepOPSD，这些方法都用了教师-学生差值，但用法各有不同：有的是当辅助损失，有的是直接缩放 token 的梯度幅度，有的是设计一个门控机制。

主要结果：AgentOPSD 在两个模型规模上，对比所有基线都有提升。具体数字方面，使用 Qwen2.5-7B 在 ALFWorld 上达到了 89% 的成功率，这是所有方法里最高的。在跟信息条件完全相同的基线对比里，也就是同样能获取技能信息的方法里，AgentOPSD 在八组对比（两个模型规模乘以四个主要基线）里赢了全部八组，或者在最强基线 SDAR 上赢了其中六组。

有一个特别有说服力的分析：把每个方法的成功率跟轨迹平均轮次数做回归，看成功率随轮次增长的下降速度。RLSD 每增加一轮，成功率下降约 2.4 个百分点；GRPO 下降约 2.1 个百分点；而 AgentOPSD 只下降约 0.8 个百分点，是所有方法里最平缓的。这直接验证了方法设计的动机：均匀信用分配对长轨迹的伤害最大，而历史依赖的信念修正恰好在轨迹最长时效果最显著。

消融实验是这篇论文的精华部分，做得非常细致。每次只去掉或替换一个组件，在 ALFWorld Qwen2.5-7B 上测成功率。完整方法是 89%。

第一个消融：把轮次级别的信念追踪换成 token 级别的累加，成功率降到 86%。原因刚才分析过，token 的粒度和环境响应的边界不对应，把一个完整动作的功劳拆散给每个字，信号就乱掉了。

第二个消融：去掉递归更新，改用每一轮孤立的局部差值，成功率进一步降到 83%。这是最核心的消融，它直接证明了论文的中心主张：局部差值不是序列信用，信念修正才是。同样的一个局部信号，放在信念状态还很不确定的时候，它能大幅改变信念，贡献很大；放在信念状态已经收敛到接近成功的时候，它的边际贡献就很小，因为结果大概率已经确定了。递归更新正是捕捉了这种上下文敏感性。

第三个消融：保留信念修正的幅度，但去掉符号对齐，也就是不区分"信念上升是否和最终结果一致"，成功率降到 85%。这说明，知道哪一步信念变化最大是一回事，但还需要知道这个变化的方向和最终结果的方向是否一致。对成功轨迹里信念下降的步骤多给惩罚，对失败轨迹里信念上升的步骤做相应处理，这种方向对齐是有实质价值的。

第四个消融：去掉先验锚点，不用组平均成功率初始化信念状态，成功率降到 87%。降幅相对较小，但仍然显著，说明为不同难度任务提供一个正确的初始参考点，对早期轮次的信用估计是有帮助的。

超参数敏感性分析也做得比较充分。重塑权重是最关键的参数，从 0 增加到 1 效果单调提升，设为 1 最好；证据衰减系数在合理范围内波动时效果变化不大，整个方法对这个参数不敏感；策略裁剪范围也基本不影响结果，说明方法继承了 GRPO 的训练稳定性。一个很有意思的现象是：在短轨迹的 Search-QA 任务上，所有超参数的效果差异都比 ALFWorld 小得多，这再一次印证了方法在长轨迹场景下才最有用，短轨迹下各种设计的影响都被压缩了。

从相关工作的角度来看，这篇论文和几个方向都有关联，值得理清楚。

在 RL 的信用分配经典方法里，PPO 通过训练价值函数加上广义优势估计来实现逐步的时序差分信号；RUDDER 把终端奖励重新分配给关键步骤；VinePPO 通过额外采样估计中间价值。这些方法都能恢复细粒度的时序信号，但代价是需要训练价值网络、奖励模型，或者大量额外采样，把 GRPO 省去这些成本的优势给抵消了。AgentOPSD 不需要额外采样，不需要学习参数，只多做一次教师的前向传播，就把信念状态当成了价值基线的替代，把信念修正当成了 TD 信号的替代，是一个代价极低的近似方案。

和 GiGPO 的关系值得一提。GiGPO 是另一个专门为智能体场景设计的 GRPO 改进方法，它通过在多条轨迹之间设置共同的"锚点状态"，用奖励端的信息来估计步骤级优势，补充了环境奖励维度的细粒度信号。AgentOPSD 则从自蒸馏证据维度提供细粒度信号，两者是互补关系，针对的信号来源不同，原则上可以结合使用。

论文也诚实地点出了局限性。首先，教师分支的特权信息需要一个技能库，这个技能库的质量和覆盖度会影响教师分支的能力上限，如果技能库匹配不准确，教师信号就会引入噪声。其次，贝叶斯信念更新的理论推导依赖两个假设，在实际训练中这两个假设是近似成立的，并不完全精确，理论保证是软性的而非硬性的。第三，方法在短轨迹任务上的增益相对有限，它本质上是为长交互场景设计的，如果你的任务只有三四轮交互，这套历史累积机制的价值就会大打折扣。

对实际工作有什么借鉴意义？

如果你在做多轮智能体的强化学习训练，用的是 GRPO 或类似无评论家框架，第一个可以直接尝试的事情是：检查你的信用分配是否在轮次边界上做了聚合，还是直接在 token 级别广播。仅仅把 token 级别的蒸馏信号换成轮次级别的聚合，根据消融结果就能带来几个百分点的提升。第二个值得借鉴的设计原则是历史依赖性：任何逐步评估的信号，都应该考虑到之前已经积累的上下文，孤立地看每一步会高估早期冗余的步骤、低估晚期关键的步骤。贝叶斯信念这个框架是一种实现方式，但核心原则是通用的。第三，这篇论文的超参数分析提示我们：不同环境共享一套超参数是可行的，不必对每个任务单独调参，这对实际工程落地是个好消息。

从更大的视角来看，这篇工作揭示了一个普遍性的道理：在序列决策里，局部信号的价值取决于全局上下文。这不只适用于自蒸馏，也适用于任何形式的逐步奖励估计。当你试图把一个轨迹末尾的稀疏奖励分解回每一步时，你需要的不仅仅是局部特征，还需要一个能追踪"到目前为止局势如何演变"的状态，而这个状态的更新才是真正的信用载体。
