当前的多模态大语言模型在空间推理上究竟卡在哪里？这篇论文做的第一件事，就是把这个问题说清楚。

想象这样一个场景：你走进一个从没去过的房间，拍了两张照片，一张朝着窗户，一张朝着门。然后有人问你，站在沙发旁边，面朝书架，窗户在你的左边还是右边？你作为人，不用拿尺子，也不用打开三维建模软件，脑子里自然会把两张照片拼成一个完整的房间模型，然后在心里旋转视角，站到那个位置上去想。这个能力，认知科学家叫它"空间智能"，它有两个核心操作：一是把多张视角的照片融合成一个统一的三维场景；二是在推理过程中随时把这个场景转换到新的视角下去理解。

这两件事，对现在的多模态大语言模型来说，做得有多糟糕？这篇论文用数据告诉你答案，然后提出了一个叫做 S-Mind 的框架来解决它。

先说背景。近年来多模态大语言模型发展很快，从 GPT-6 Astra、Kimi K3.1 Pro，到各种开源的视觉语言模型，视觉理解和推理能力都在突飞猛进。但这些模型越来越多地被用在具身智能、自动驾驶、扩展现实这类需要真正理解三维空间的场景里。空间智能因此成了一个绕不过去的瓶颈。

针对这个问题，之前的研究大致走两条路。第一条路叫外部几何方法：把三维重建或者几何编码器架在模型外面，推理的时候调用这些工具，给模型提供显式的几何信息。比如 SpatialClaw 这类工具型的智能体，会在回答一个问题的时候调用外部重建工具、分割工具，平均每道题要调用主干模型将近八次，外部工具也要调用将近五次。这种方法虽然几何信息准确，但推理延迟非常高，而且几何能力只是外挂的，模型本身并没有真正学会空间推理。

第二条路叫空间微调方法：通过训练让模型内部自己形成空间能力，不依赖外部工具。这条路看起来更有前途，所以近年来吸引了很多研究者。这类方法的监督信号从最早的只看输出文本，逐渐延伸到对模型内部隐藏状态的监督，越来越多的工作试图让模型的中间表示和三维几何对齐。

但问题在于：这些方法的评估大多只看最终答题的准确率。准确率提升了，就说模型内化了空间能力。这个推断合理吗？这篇论文的作者们不满足于此，他们设计了两个叫做"空间探针"的工具，直接去检测模型内部到底存了什么。

探针的设计思路是这样的。几何探针：冻结整个模型的参数，在图像后面加几个可训练的探针 token，然后从这些 token 的隐藏状态里试着解码出每个视觉 token 对应的三维点坐标。如果模型确实在内部融合了多张图片的信息，就应该能从探针 token 里读出跨视角的三维点。视角探针：在多模态模型里有一种叫 S-Space 的分析方法，它发现模型中间层存在线性编码物体位置的轴。利用这个工具，可以在模型推理过程中读取它对场景中两个物体位置的内部表示，然后测试这个表示是否随着推理中宣告的视角变化而旋转。

用这两个探针去检测经过空间微调的模型，结果非常清晰，而且相当令人沮丧。

第一个发现叫做"多视图融合严重不足"。在 Qwen3.5-4B 的基础模型上，探针能从第一张图的视觉 token 里恢复出 60.62% 的三维点，这说明单张图的感知是有的。但对于其他图片的三维点，恢复率只有 11.23%。这些点之所以难恢复，是因为它们必须通过把多张图的信息关联起来才能定位，也就是需要真正的多视图融合。经过 SFT 微调之后，这个数字从 11.23% 只提升到了 14.19%；经过 GRPO 强化学习之后，到了 16.02%。两个已公开发布的空间推理模型 3DThinker 和 GPD，表现是 10.65% 和 11.82%，几乎没有改善。这说明空间微调基本没有解决多视图融合的问题。这个结论还能从行为上得到印证：在 MindCube-Tiny 这个基准测试里，有 274 道题专门考查两张图的位置关系，SFT 和 GRPO 的准确率只有 53.28% 和 56.57%，错误几乎都是把第二台相机放在了镜像的方向上，说明模型确实没有在内部把两个视角正确地对齐。

第二个发现叫做"视角变换严重不完整"。在 SpinBench 这个基准上，题目要求从某个非相机原点的视角来判断两个物体的位置关系。研究者发现，模型内部的隐藏状态实际上已经正确编码了场景，只要在外部手动旋转坐标系，就能从状态里读出 95.14% 的正确关系。但如果直接在目标视角的坐标系里读，准确率只有 33.44% 到 47.15%，说明模型内部的场景表示根本没有随着推理中宣告的视角而转动。在推理链中宣告了新视角的情况下，从声明视角的坐标系里读取场景，平均准确率只有 30.02%，几乎等于随机猜测的水平 25%。同样地，SFT 和 GRPO 对这个问题没有改善。

这两个发现合在一起，揭示了一件很重要的事情：现有的空间微调方法提升了模型的答题准确率，但这种提升背后并没有真正的多视图融合和视角变换能力。模型学到的是某种更表面的启发式规律，而不是人类理解三维空间的那两种底层操作。

于是论文提出了 S-Mind。整体思路是：在模型自己的 token 序列里，给三维场景分配专属的位置，然后直接监督这些位置的隐藏状态，让模型学会在内部构建并操控一个完整的三维场景。

具体来说，S-Mind 在所有输入图片后面附加一组"空间 token"。这组 token 被分成两类：一类叫场景 token，每个视角有若干个，负责编码那个视角观察到的几何信息；另一类叫相机 token，所有视角共享，负责编码每台相机在统一坐标系里的位姿。这些 token 的隐藏状态就是模型对整个三维场景的内部表示，它们普普通通地待在序列里，后续推理通过普通的注意力机制就可以看到它们，不需要改变任何模型架构。

怎么训练这组空间 token 真的去融合多视图？这里有一个叫做"几何读出"的机制。设计上，读出器的查询向量只编码视觉 token 在图像网格里的位置，不携带任何图像内容。这意味着读出器能从空间 token 里读出什么，完全取决于空间 token 的隐藏状态已经存了什么。通过对空间 token 的隐藏状态施加监督，要求它们能解码出每个视觉 token 对应的三维点坐标和相机位姿，模型就被迫在训练过程中真的去融合多张图片的信息，把它们统一到第一个视角的坐标系下。损失函数使用 Huber 损失，同时对全局坐标、局部坐标和相机位姿都施加监督，这种冗余监督是故意设计的，因为这三个量互相决定，让它们都被约束会促使模型形成一个自洽的三维场景。

这个几何预训练阶段在 ScanNet 数据集上进行，ScanNet 提供了大量带有相机位姿标注的室内场景图像序列，非常适合这个目的。

第二个核心设计是视角变换。融合好的三维场景是以第一张图的坐标系为基准的。但推理过程经常需要切换到另一个视角，比如"假设你站在门口，面朝窗户，左边是什么"。S-Mind 的做法是：每当推理链中宣告了一个新的视角，模型就重新发射一组空间 token，这些重新发射的 token 负责把融合好的三维场景在新视角的坐标系下重新表达一遍。重新发射的 token 紧跟在视角声明之后，它们能同时看到之前融合好的空间 token 和刚刚宣告的视角，所以模型只需要用语言宣告一个视角，就能驱动空间 token 把整个场景转过去。

这里的监督信号用的是一个停梯度技巧：从融合阶段的空间 token 里解码出全局三维点，然后用当前新视角的相机位姿做刚体变换，得到这些点在新坐标系里的坐标，让重新发射的空间 token 对准这个目标。停梯度确保监督只告诉模型如何变换场景，而不干扰感知部分的学习。

整个训练分三个阶段。第一阶段是几何预训练，在 ScanNet 和 MindCube 的带位姿图像集上，让空间 token 学会融合多视图。第二阶段是在推理链上做 SFT，把视角变换和语言推理联合训练，同时还有一个权重参数平衡几何监督和语言监督；这里的一个关键发现是，只要有哪怕很小的正几何权重，预训练获得的几何能力就能保住，完全去掉几何监督的话，空间 token 里能解码的三维点会从 76.13% 下降到 48.79%，重新发射的 token 也会失去视角变换的能力。第三阶段用 GRPO 强化学习，以最终答案的正确性作为奖励信号，让模型学会如何把变换好的场景用于做判断。

模型选用了 Qwen3.5-4B 和 Qwen3.5-9B 两个规模，用 LoRA 训练所有阶段。每个视角使用 16 个场景 token，外加 4 个相机 token，总量非常紧凑。

在四个测试基准上的结果非常有说服力。这四个基准分别测试不同侧面的空间能力：MindCube-Tiny 测心理建模，就是从有限视角构建三维心理模型；SPAR-Bench 测空间关系推理；BLINK 测空间感知；ViewSpatial-Bench 测视角转换。

S-Mind 在 Qwen3.5-4B 上的四个基准平均准确率达到 72.83%，比同等设置下训练的最强基线 ProSR 高 7.65 个百分点，比已公开发布的最好空间推理模型 Spatial-Interactor-4B 高 17.91 个百分点，而且在全部四个基准上都排第一。扩展到 Qwen3.5-9B 之后，平均准确率达到 74.03%，比 GRPO 高 6.76 个百分点，比 SFT 高 11.76 个百分点，同样四个基准全部第一。在 9B 规模上，S-Mind 和 GPT-6 Astra 的 73.58%、Qwen3.8-Flash 的 73.98%、Claude-Opus-5.5 的 74.15% 基本持平，而且在 4B 的时候就已经超过了 GLM-5.3-Flash 的 66.23% 和 Kimi-K3.1-Pro 的 72.06%。

这些数字说明：一个参数量非常紧凑的开源模型，只要正确地内化了空间能力，完全可以达到前沿闭源大模型的水准。

推理效率的对比也很显著。和 SpatialClaw 这个工具型智能体相比，S-Mind 不需要任何工具调用，单次生成就能回答问题。在 MindCube-Tiny 上比它快 81 倍，在 ViewSpatial 上快 115 倍，同时准确率分别高出 31.05 和 9.17 个百分点。

探针实验对结果的来源做了仔细的验证。几何探针显示，S-Mind 能从空间 token 里恢复出 65.11% 的跨视图三维点，而基线最高只有 16.02%。单视图点的恢复率是 86.32%，也明显高于基线的最高 60.62%。跨视图方向预测达到 85.35%，相机朝向恢复率达到 93.55%。更重要的是，当图片数量增加时，S-Mind 的优势更加明显：基线在 8 张图时只能恢复不到 5% 的跨视图点，S-Mind 仍然能恢复 50.52%。

视角探针显示，S-Mind 在声明视角的坐标系里读取场景的准确率达到 82.17%，而基线在 25.22% 到 37.28% 之间，接近随机水准。把这个结果按方向细分：前方的点各模型都能恢复，但后方、左方、右方的点，基线最高分别只有 10.29%、9.78%、40.69%，而 S-Mind 达到了 77.38%、69.51%、85.29%。两个控制实验也很重要：当探针尝试读取的是推理链中另一个不同视角时，准确率下降到 30.10%；当读取的是视角声明之前的 token 时，准确率是 29.43%。这说明场景的转换是绑定在视角声明这个动作上的，不是碰巧的，是真实的。

研究者还做了一个因果干预实验，更直接地证明空间 token 的内容确实在驱动答案。他们在推理阶段替换最后一次重新发射的空间 token 的隐藏状态，把它换成融合阶段的状态，也就是把转换好的视角场景换回原始场景。结果是 9.05% 的答案发生了改变，而且大多数是从正确变成错误。对照组是用同等范数的随机扰动，只改变了 1.62% 的答案。在"想象视角"这种问的视角根本没有对应输入图片的情况下，替换导致 20.86% 的答案改变；在相机旋转设置里，视角间重叠很少，改变率达到 28%。这组实验确认了因果关系：不是空间 token 碰巧出现在那里，而是模型真的在用它们推理。

消融实验进一步拆解了每个设计的贡献。把无监督的空间 token 加进去，也就是只有语言损失训练它，对准确率的影响不超过 1.24 个百分点，说明额外的 token 和计算本身没什么用，关键在监督。加上几何监督之后，MindCube-Tiny 从 74.00% 升到 81.81%，BLINK 从 68.25% 升到 71.75%，提升最为显著。再加上视角监督，两个基准进一步提升，BLINK 在多视图题目上的提升尤为明显，从 52.63% 升到 59.40%。对于跨视图的那 274 道难题，只加几何监督就把准确率从 56.57% 提升到了 94.89%，这个结果说明多视图融合能力是这类难题的真正瓶颈。

有一个很有意思的附加发现值得单独讲一下。研究者测试了如果在推理时把所有空间 token 都隐去，模型表现会怎样。平均准确率从 72.83% 下降到 70.46%，只掉了 2.37 个点。更重要的是，即使在没有空间 token 的情况下，S-Mind 在每个基准上仍然比最好的基线高出平均 5.28 个点。这说明空间能力已经真正内化进了主干模型，而不只是依靠空间 token 在推理时携带。空间 token 在训练中扮演的是一个"教学支架"的角色，它在训练时把几何监督信号注入模型权重，训练结束后，能力已经渗透进了主干，空间 token 只是锦上添花。这个发现对于实际部署很有意义，意味着即使在资源受限的场景下也能用上这个模型。

对于熟悉大语言模型内部机制的人，论文里还有一个分析很有参考价值：他们逐层跟踪几何融合发生在模型的哪个位置。在 Qwen3.5-4B 上，从输入层到第 8 层，从空间 token 里能读出的跨视图信息和全零状态读出的基本一样，说明融合还没开始。从第 9 层开始信息开始积累，在第 11、15、19 层这三个全注意力层（因为 Qwen3.5 是混合注意力架构，部分层是滑动窗口注意力），融合信息出现三次最大的跃升，每次跳升 12 到 15 个百分点。从第 19 层之后，每一层单独都能恢复接近综合读出器水平的跨视图信息。这说明三维场景在中间层形成之后，会被完整地携带到最后一层，供推理使用。

论文也诚实地指出了局限性和未来方向。S-Mind 目前的几何监督只覆盖输入视角观察到的区域，没有看到的地方模型不会主动补全。对于长时间交互的具身智能体、需要在探索中不断更新场景模型、或者场景是动态变化的情况，当前框架还力不从心。作者把这些留给未来的工作：让内部场景表示能够跨交互步骤持续存在，并随着动态环境演化，让同一组空间 token 能在长时序任务中支撑智能体推理。

从方法论上，这篇论文对做多模态空间推理研究的人有几个具体的可借鉴之处。第一，不要只看任务准确率，要去挖掘模型内部表示，探针技术是检验"能力是否真正内化"的有效手段，而不是昂贵的可解释性工具。第二，给模型预留专属的"工作内存"位置，直接对这些位置的隐藏状态施加中间监督，比只在输出层施加损失有效得多，这种设计对于需要中间计算状态的任务有普遍的参考价值。第三，冗余监督是一种有效的正则化策略，让多个互相决定的量都对准目标，能显著提高场景表示的自洽性。第四，空间 token 在推理时的信息可以通过因果干预来验证是否真正被使用，这是区分"存了几何信息"和"用了几何信息"的关键区别。

这篇工作最深层的贡献，是把"空间智能是否内化"这个问题从一个定性说法变成了可以用探针直接测量的量化指标，然后设计出一个能在这个指标上真正达标的框架，并且在推理效率上没有付出任何代价，反而比工具型方法快了两个数量级。这说明，让模型真正"想清楚"三维空间，并不需要在推理时调用外部几何工具，只需要在训练时认真地教会它融合视角、转换视角，能力就会成为它自己的一部分。
