好的，我们来聊一篇关于视频和音频联合生成模型训练的最新论文，叫做 Prism。

这篇文章要解决的核心问题是：我们现在已经能生成高质量的视频和音频了，但大部分模型都无法在“原生”的 2K 高分辨率下进行训练。这就像你拍照，虽然可以把低分辨率的图片放大，但细节总归是有限的，甚至会放大瑕疵。如果能直接在 2K 甚至更高的分辨率下训练，模型就能学到更丰富的视觉细节和更清晰的运动动态。

那为什么之前做不到呢？主要原因在于全注意力机制的计算成本太高了。在 2K 视频里，一个短短 12 秒、每秒 24 帧的视频，经过 VAE 压缩后，会产生超过一百万个 token。全注意力机制的计算复杂度是 token 数量的平方，这就意味着计算量会呈几何级数增长，导致训练成本高得惊人。更糟糕的是，在高分辨率下，视频里新增的 token 很多都是重复的背景，真正有信息量的内容，比如人脸、快速运动，仍然是局部化的。全注意力机制会不加区分地对待所有 token，导致有用的信息被大量冗余 token 稀释，反而会干扰模型对关键内容的学习，甚至破坏预训练好的先验知识。

现有的稀疏注意力方法虽然能降低计算成本，但它们要么是为了推理加速而设计的，要么只关注纯视频生成，没有考虑到视频和音频联合生成数据的独特结构。这种独特结构是什么呢？就是跨模态的交互，比如声音和嘴唇的同步，通常都集中在产生声音的区域。如果稀疏注意力策略不能适应这种跨模态结构，就会丢失关键的依赖关系，影响联合生成的效果。而且，在 2K 分辨率下，大量的重复背景 token 会进一步淹没稀疏选择信号，让模型更难识别出真正有用的关键 token 对。

为了解决这些痛点，Prism 提出了一种动态稀疏注意力框架，专门用于在原生 2K 分辨率下训练视频和音频联合生成模型。

Prism 的核心思想是：注意力机制应该根据内容来动态调整。它首先把视频 token 序列划分成时空“宏区域”，每个区域的注意力结构都可以根据局部内容进行调整。具体来说，对于每个宏区域，Prism 会通过两种互补的指导信号来评估其局部信息结构：

第一种是“视频通道方差指导”，它衡量的是视频特征沿着每个时空轴（时间、高度、宽度）的变化速度。想象一下，如果一个区域的视觉内容变化很快，比如一个快速移动的物体，那在这个轴上就需要更精细的划分。

第二种是“音视频交叉注意力范数指导”，它衡量的是音频对每个视觉区域的影响强度。因为音视频同步通常集中在发声区域，所以这个指导信号能帮助模型识别出那些与音频紧密相关的视觉区域。

Prism 会综合这两种信号，为每个宏区域动态分配一个量身定制的 3D 块形状。具体来说，它会在视觉内容变化快或音视频耦合强的轴上进行更精细的划分。这样做的目的是确保每个块内部的 token 在语义上保持一致，从而让块级别的特征能够更好地捕捉视觉内容和音视频交互模式。

传统的稀疏注意力方法通常会使用固定的块形状，但这在 2K 视频中是行不通的。在高分辨率下，视觉细节和冗余 token 都大量增加，但它们的分布很不均匀。比如，发声区域通常在空间上很紧凑，但在时间上变化很快；而静态背景则包含大量重复的 token。如果使用固定形状的块，就可能把语义不相关的 token 混在一起，导致块代表的特征不可靠，进而影响训练效果。Prism 的动态块形状机制就是为了解决这个问题。

我们来深入了解一下 Prism 的动态块形状是如何实现的。

首先，Prism 将视频 token 网格划分成不重叠的宏区域。这些宏区域的尺寸是固定的，这样方便使用 Triton 内核进行计算。之所以选择宏区域，而不是更细粒度的 token 级别动态形状，是因为 Triton 内核需要内存连续的块，token 级别的动态形状会导致不规则的内存访问，效率不高。而且，在 2K 这种大尺度下，每个宏区域本身已经足够小，内容相对均匀，区域级别的决策就足够了。

接下来，在每个宏区域内，Prism 会计算一个“变化指示器”，它结合了前面提到的两种指导信号：视频通道方差和音视频交叉注意力范数。这个计算是独立于每个注意力头和每一层的，这意味着不同的注意力头和不同的层可以根据它们各自的特征分布来调整块形状。

视频通道方差指导的计算方式是：Prism 会聚合宏区域内沿着每个轴（时间、高度、宽度）的“值”特征。之所以选择值特征，是因为它们直接用于注意力输出的聚合，所以它们的方向变化最能真实反映块边界。然后，它会测量这些特征在每个轴上的变化程度。变化越大，说明这个轴上的视觉内容变化越快，就需要更精细的块划分。它还会将这个变化程度归一化成一个各向异性比率。

音视频交叉注意力范数指导则捕捉了每个区域中音视频耦合的方向结构。在 DiT 模型中，每个视频隐藏状态都会受到音视频交叉注意力的调制。这个交叉注意力编码了多少音频信息被注入到每个视频 token 中。Prism 会计算每个宏区域的音频耦合强度，并进一步捕捉音频影响的方向结构。比如，唇部区域在时间轴上可能具有较高的音频方差，因为嘴巴会张开和闭合。

然后，Prism 会将这两种指导信号结合起来。在一个发声区域（音频耦合强度高），它会引导块形状的分配更多地考虑音视频耦合。而在一个静音区域（音频耦合强度低），音频项的影响就会消失。

有了这个“变化指示器”，Prism 就会从一个预定义的候选块形状集合中，为每个宏区域选择一个最合适的 3D 块形状。这些候选形状的尺寸是经过精心设计的，既能提供细粒度的块用于细节丰富的区域，也能提供更大的块用于大量重复的静态背景，还能有中间尺寸的块用于过渡区域。

Prism 将形状分配问题建模为最小化块内信息损失。直观来说，如果一个轴上的内容变化很快，那么沿着这个轴把更多 token 组合在一起就会导致平均池化后的代表信息损失更大。所以，变化最大的轴应该分配最短的边缘长度，也就是最精细的划分，从而保持块内部的语义一致性。Prism 通过拉格朗日乘数法得到了一个闭式解，并将其量化到最近的候选形状。

动态块形状解决了块内部语义一致性的问题，但注意力机制还需要决定每个查询应该关注哪些关键块。为此，Prism 采用了“动态每查询稀疏度”策略。

传统的块选择策略通常会采用固定的稀疏率，即为每个查询选择相同数量的关键块。但在实际中，处于显著区域的查询可能只需要关注少数几个附近的块，而处于均匀区域的查询可能需要更广泛地分散注意力。固定的选择策略对前者来说是浪费的，对后者来说又是不够的。

Prism 的方法是结合了“Top-K”和“Top-P”两种策略来动态确定每个查询的稀疏度。

Top-K 策略会选择注意力权重最高的 K 个块，这保证了最低限度的覆盖。

Top-P 策略则会选择最小的一组块，使它们的累积注意力权重超过一个阈值 P。

通过结合这两种策略，Prism 可以实现动态调整。对于注意力集中的查询，它会选择较少的块；而对于注意力分散的查询，Top-P 策略会自适应地扩展注意力范围，从而集中计算在真正有信息量的交互上。这个 P 值也是动态变化的，可以根据查询的注意力分布来调整。

在训练方面，Prism 只将这种稀疏注意力应用于视频自注意力部分，因为在 2K 分辨率下，这部分是主要的计算成本。而交叉注意力和音频分支的序列长度要短得多，计算成本可以忽略不计。模型使用视频/音频流匹配损失进行训练。

接下来我们看看实验结果。

在实现细节上，Prism 的训练数据集包含了 10 万个 2K 视频和音频片段，这些数据经过了严格的筛选，确保了高分辨率的质量，并排除了低分辨率放大、视觉平坦或静态的视频。数据集特别强调了包含大量运动的场景，比如人与物体的互动、多人对话、歌唱表演等等，因为原生 2K 训练对于学习复杂的运动模式特别有益。Prism 是在 MOVA 模型的基础上进行初始化的，并训练了 5 个 epoch。

定量结果显示，在 2K-Bench 数据集上，MOVA、Ovi 和 MagiHuman 等使用全注意力机制的模型，即使在相同的原生 2K 数据上训练，性能也比 Prism 差。这证实了在 2K 分辨率下，全注意力机制确实会导致注意力权重稀释，大量冗余 token 占据了大部分注意力权重，导致有信息量的内容得不到充分关注，并破坏了预训练的先验知识。而 LTX-2.3 模型虽然也能生成 2K 视频，但它是在 720p 生成后再上采样到 2K 的，所以视觉细节受限于低分辨率阶段，超分辨率只会放大现有瑕疵。Prism 通过动态地将注意力集中在有信息量的块上，克服了这些问题，使模型能够吸收原生 2K 训练提供的更丰富的视觉细节和更清晰的运动动态。

即使在 720p 的 VABench 和 MOVA-Bench 数据集上，Prism 仍然优于所有竞争对手，尽管优势较小。这是因为序列越短，冗余越少，全注意力机制的危害和稀疏注意力机制的益处也就越小。

定性结果也很明显，其他竞争模型经常出现闪烁、视觉模糊和人体变形等问题，而 Prism 生成的视频在结构上保持了高度的一致性，因为它能够有效地捕捉原生 2K 训练提供的丰富视觉细节和清晰运动模式。

与业界领先的商业模型相比，Prism 虽然在视觉真实感和音频美学方面仍有差距，这主要是因为商业模型拥有更大的模型参数和数据集。但在大运动场景下的音视频稳定性方面，差距已经显著缩小。这表明 Prism 显著缩小了开源模型与业界领先模型之间的差距。

消融实验也提供了很多有趣的发现。

首先是稀疏注意力机制的消融。实验证实了全注意力在 2K 分辨率下表现不佳，因为它被大量的冗余 token 所淹没。固定形状的块稀疏注意力效果最差，因为它在异构时空结构区域混合了语义不相似的 token，破坏了块代表的特征。其他可训练的稀疏注意力方法有所改进，但它们都忽略了音视频联合数据特有的跨模态耦合结构，导致其均匀的稀疏模式在 2K 分辨率下不足。而训练无关的方法表现甚至低于全注意力，因为它们只是近似一个本身就次优的模型输出。Prism 在运动质量和音视频同步方面都显著优于其他稀疏注意力方法，这表明其内容自适应的块形状确实能够集中在真正有信息量的交互上。

在原生 2K 训练/推理方法的消融实验中，训练无关的方法表现很差，因为 720p 预训练的骨干网络从未接触过 2K 分辨率下才出现的注意力模式。级联方法（如 PyramidFlow 和 LUVE）无法在单次去噪过程中学习所有 2K token 的联合分布，引入了低分辨率偏差。空间结构和运动模式在粗略网格上确定，精度有限，后续的细化阶段无法在上采样后重构它们。音视频同步也受到限制。T3 虽然在 2K 下原生训练，但它以均匀的步幅采样 token，这与内容无关。Prism 则通过原生 2K 训练和内容自适应的动态稀疏注意力，克服了这些局限性。

动态块形状的消融实验也很有说服力。固定形状和随机形状的块表现最差，证实了与内容无关的分配会破坏块代表。Prism 的三层分配策略在质量和速度上都优于单一最精细层。移除视频指导会导致最严重的视觉质量下降，而移除音频指导则会降低音视频同步指标，这揭示了它们各自的互补作用。此外，实验也验证了空间和时间方差对于方差估计的重要性。

关于稀疏度的消融实验表明，仅使用 Top-K 策略会缺乏最小覆盖，丢失关键上下文。而仅使用 Top-P 策略在 85% 的阈值下能达到最佳的单一策略质量。Prism 混合了 Top-K（95%）和 Top-P（0.2）策略，结合了最小覆盖和对分散查询的自适应扩展，实现了最佳的质量-速度权衡。

对不同骨干网络的消融实验也验证了 Prism 的鲁棒性，它可以适用于不同的 DiT 骨干网络。

可视化结果也很有趣。训练损失图显示，Prism 在两种模态上都实现了最低且最稳定的损失，而全注意力表现出不稳定性，其他稀疏方法则显示音频损失上升，这证实了内容无关的注意力未能捕捉 2K 分辨率下的跨模态耦合。注意力图和块形状分配的可视化显示，Prism 的动态块形状机制能够根据局部内容自适应地切换时间、空间和音视频划分的粒度，这表明其形状分配是基于原理而非任意的。

在应用方面，Prism 相比于全注意力的 MOVA 模型，推理时间减少了 3 倍，GPU 内存减少了 47%，同时在各项质量指标上都有显著提升。与领先的竞争对手 LTX-2.3 相比，Prism 实现了可比的推理速度，但在所有质量指标上都表现出色。

用户研究也进一步证实了 Prism 在主观评价上的优越性，参与者普遍认为 Prism 生成的视频在视觉/音频与文本提示的对齐、视觉/听觉/运动细节质量以及音视频同步方面都表现更好。

总结来说，Prism 提供了一个非常有效的解决方案，用于解决在原生 2K 分辨率下训练视频和音频联合生成模型的挑战。它通过动态稀疏注意力，特别是通过将 token 序列组织成时空宏区域，并根据视频通道方差和音视频交叉注意力范数动态分配定制的 3D 块形状，确保了每个块在语义上的一致性，从而有效地捕捉视觉内容变化和音视频耦合。同时，混合的每查询稀疏度策略进一步集中了计算资源在有信息量的交互上。对于我们研究方向的听众来说，Prism 的核心思想——即注意力机制应该根据内容进行动态调整，并且要充分考虑跨模态数据的独特结构——是非常有启发意义的。特别是在处理高分辨率、多模态数据时，这种细致入微、内容感知的稀疏化策略，能够显著提升模型的效率和生成质量。
