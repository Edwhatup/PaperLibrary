有一个问题摆在桌面上：AI智能体系统里，模型的推理能力已经被内化到基础模型本身了，比如深度思考、链式推理，这些能力现在都是模型原生自带的。但是记忆能力呢？记忆到今天还是靠外挂模块来实现的。你把一段对话历史存到数据库里，需要用的时候再检索回来，塞进提示词的上下文里，让模型去读。这就是绝大多数所谓"有记忆"的AI系统的实现方式。

这篇论文的核心主张是：这条路走到头了，或者至少走不远。外挂记忆有三个根本性的缺陷，而解决这些缺陷的唯一出路，是把记忆能力直接内化到模型的前向计算里面，就像当年把推理能力内化成思维链一样。基于这个主张，这篇来自MemTensor、人民大学、新加坡国立大学、上海交通大学等机构的团队，提出了一个叫做Metis的原型系统，他们称之为记忆基础模型。

先说清楚外挂记忆的三个根本性缺陷，这是理解整篇论文动机的关键。

第一个缺陷叫做目标解耦。外挂记忆系统的目标是构造一段信息丰富的上下文，然后把这段上下文塞给模型作为输入。模型本身只是在这段被构造好的上下文上做条件语言建模。这两件事是分开的，目标是分开的，处理阶段是分开的。问题在于，检索出来的信息不一定是对模型推理最有用的信息，而模型也没有办法对存储阶段施加影响，去告诉系统"我需要你记住的是这个，不是那个"。整个系统里，存储端和使用端是两套独立的优化目标，天然存在不对齐。

第二个缺陷叫做端到端优化困难。外挂记忆通常涉及离散操作，比如往数据库里写一条记录、从数据库里删一条记录、做向量检索。这些离散操作没有办法对梯度进行有效传播。这意味着你很难对整个记忆加推理的链路做端到端的微调。你想针对特定领域做定制化训练，就会遇到巨大障碍。虽然有些基于强化学习的方案可以部分绕开这个问题，但效率代价很高。

第三个缺陷叫做推理延迟开销。外挂记忆在推理的时候需要额外的显式操作：先做检索，然后把检索到的文本拼接进上下文，然后做预填充。这些操作每次推理都要做，不可避免地增加延迟。而且随着历史交互变多，被检索的文本可能越来越长，预填充的代价也线性增长。

这三个缺陷不是工程问题，而是范式问题。论文作者的判断是，只要记忆还是外挂的，这三个问题就没有根本性的解法。

所以这篇论文提出的概念是：记忆基础模型，英文叫Memory Foundation Model。它的核心思想是把记忆从外部模块转化成模型骨干网络内部的一个机制，直接参与前向计算。

作者给这个概念做了精确的形式化定义，围绕两个核心要素展开。

第一个要素叫做原生记忆状态，Native Memory State。在传统的语言模型里，模型的参数是静态的，推理完了之后参数不变。记忆基础模型不一样，它的部分参数是动态的，跨多步交互持续存在并演变。具体来说，在第t步交互时，模型的参数θ包含一个动态分量，这个动态分量就是记忆状态，它携带了从第一步到第t步累积起来的历史信息。这个记忆状态是参数化的，也就是用稠密的矩阵来表示，而不是一段文本。用稠密矩阵表示有两个好处：信息密度高，不像文本那样每次使用都要重新做预填充；而且这个动态参数和模型的静态参数在同一个语义空间里，通过预训练或者中间训练阶段的对齐，它们可以协同参与前向计算。

这里有一个很重要的边界定义。作者明确说，他们只把交互开始之后获取的信息算作记忆。交互开始之前模型通过预训练学到的那些知识，不叫记忆，叫知识。知识不包含特定用户、特定对话轨迹的个性化信息，也不需要实时更新。这个区分有实际意义：记忆状态是一个动态参数，专门用于存储在线交互期间收到的信息。

第二个要素叫做原生记忆程序，Native Memory Procedure。它包含两个子程序：记忆存储和记忆利用。记忆存储负责把当前输入的信息写入记忆状态，涵盖记住、遗忘、更新这些操作。记忆利用负责在生成回答的时候，把记忆状态里的信息引入前向计算。

论文特别强调，这两个子程序都必须在连续函数空间里建模，通过数值计算来实现，而不是通过离散规则来实现。为什么？因为人类语言里的记忆意图是语义层面的，很难被有限的离散规则覆盖。"Alice今年24岁"这句话隐含着记住她年龄的意图；"Bob从伦敦搬去了波士顿"这句话隐含着更新他位置的意图。这些意图必须通过语义理解来捕捉，而不是靠关键词匹配或者预定义的规则触发。更深层的原因是：记忆存储的本质是一个预测问题——模型要预测当前收到的信息在未来会怎样被使用。离散规则的函数空间太小，无法达到最优的预测性能。

好，概念清楚了，现在说Metis是怎么具体实现的。

Metis在架构上的核心创新是在Transformer的基础上引入了Metis块。每个Metis块包含两个子组件：本地记忆块（Local Memory Block）和超记忆块（Hyper Memory Block）。

本地记忆块是记忆状态的载体。它维护一个稠密记忆网络M，这是一个矩阵，在每一步交互之后都会被更新。同时还维护一个查询-键归一化向量n，用于数值稳定。这个M就是记忆的物理存储介质。

超记忆块是记忆程序的执行器。它的参数是在中间训练阶段学习到的，在线推理时保持冻结。它的作用是：根据当前输入的中间激活，计算出应该往M里写入什么信息。超记忆块里有几个关键的可学习参数：一个重要性向量，用来给输入序列里的各个位置打分，选出最重要的那些位置；记忆键投影矩阵和记忆值投影矩阵，把选出来的隐藏状态映射成记忆的键和值；还有一个记忆查询投影矩阵，用于从M里读取信息。

记忆存储的过程是这样的。在第t步结束时，超记忆块先对第l层的输入隐藏状态做预归一化，然后用重要性向量给每个位置打分，得到一个重要性分布。然后做一个top-k式的选择，选出重要性最高的那些位置，但不是硬截断，而是基于累积概率阈值：不断加入概率最高的位置，直到累积概率超过某个阈值τ。这个设计让选出的位置数量是自适应的，而不是固定的。

由于这个top-k选择操作是不可微分的，训练时用了直通估计器，让梯度可以通过稠密的概率分布回传，使得重要性打分器可以做端到端训练。

选出的位置对应的隐藏状态，经过记忆键和值投影之后，就得到了要写入M的键和值。M的更新公式用的是Gated Delta Network，简称GDN的更新策略，这是一种类似增量更新的方式，新信息会以加权的方式融入现有的记忆矩阵，同时有一个折扣因子控制历史信息的衰减。消融实验表明，GDN更新策略比普通线性更新性能更好。

记忆利用的过程叫做记忆注意力，Memory Attention。在当前步的前向计算里，除了标准的自注意力之外，还额外做一次对M的注意力查询：用当前输入的记忆查询状态，去查询M里存储的键值对，得到一个记忆读出。然后把这个记忆读出和标准自注意力的输出做加权融合，用一个可学习的参数α来平衡这两个分支。

这里有一个很重要的设计细节：记忆查询使用的是独立学习的投影矩阵，而不是直接复用标准注意力的查询向量。为什么要这样设计？论文给出了严格的理论分析。

记忆矩阵M里存储了多步交互的历史信息，当你用某一步的查询去读M的时候，你真正想要的是那一步相关的信息，但M里同时存着其他步的信息，这些不相关的信息会作为噪声泄漏到读出结果里。通过学习一个专用的记忆查询投影，模型可以重塑跨步的相似度结构，也就是在记忆查询的视角下，让相关步骤的键被突出，不相关步骤的键被压制，从而降低噪声的影响。论文的误差分析表明，误差项里总是包含不相关步骤相似度的因子，当这个相似度很小的时候，误差就小。所以学习专用记忆查询的本质是学习一种"过滤器"，让读取操作更精准。

效率方面，Metis有一个重要的设计：标准注意力分支、记忆注意力分支、记忆存储更新这三个操作，可以大量并行执行。记忆利用只需要读现有的M，不依赖本步注意力的输出；记忆存储只更新M供下一步使用，不影响当前步的推理路径。所以这三个操作的依赖关系允许高度并行，层级延迟接近三者中最慢的那个，而不是三者之和。而且Metis的记忆状态是固定大小的，不像RAG那样随着历史变长而需要处理越来越长的上下文。

接下来说训练数据的构建，这部分工作量相当大。

论文构建了两类数据：主要数据和辅助数据。

主要数据用于训练原生记忆程序，基于27个公开基准数据集合成，总计357137个样本，约4.06亿个token。数据按照三个维度组织：记忆操作类型、指令显著性、噪声水平。

记忆操作类型包括四种：记住、遗忘、更新、反思。记住是陈述一个事实然后查询它；反思是陈述多个单跳事实然后查询它们的多跳组合；更新是先陈述一个事实，再修改它，然后查询新值；遗忘是先陈述一个事实，再撤销它，然后查询。

指令显著性分两种：显式指令，比如"请记住Bob住在波士顿"；隐式叙述，同样的信息但以自然叙述的方式出现，不带明显的记忆指令。这个区分很重要，因为现实中大量需要被记住的信息是隐式的。

噪声水平方面，有干净序列和噪声序列，噪声序列是在参考信息和查询之间插入无关的对话轮次，用于训练长程记忆保持能力。

合成流程分三步：种子提取，从源数据集中提取参考、查询、答案，总结成结构化的主-关系-值三元组；静态合成，用强语言模型把这个三元组改写成显式和隐式两种风格，并插入干扰轮次；质量验证，用语言模型作为判官过滤，检查一致性、正交性、无捷径等条件，不通过的样本直接丢弃。

辅助数据用于提升复杂场景下的泛化能力，针对两类失效模式：干扰（相似事实被混淆，或遗忘操作误伤了应该保留的信息）和记忆污染（存储的信息泄漏到不需要它的回答里）。辅助数据包含四种子类型：多实体绑定，同时存储两个容易混淆的事实然后两个都查；选择性遗忘，存储两个事实后只撤销一个，两个都查；记忆后对话，记忆查询之后紧接着一个普通对话轮，模型不应该把记忆值带进去；记忆无关对话，即便记忆状态存在，回答一个不需要记忆的问题也不应该受影响。辅助数据合计609443个样本。

训练策略方面，Metis采用三个训练目标，冻结骨干网络参数，只训练新引入的记忆参数。

记忆重建目标：教模型把信息无损地存入M然后重建出来，这提供了信息存储能力的上界训练信号，在模型训练初期作为热身很重要。

记忆操作目标：教模型根据指令的语义意图，正确执行记住、遗忘、更新、反思这些操作。这里用主要数据的显式隐式样本和干扰样本分别训练，一个负似然损失覆盖所有操作类型，因为操作的正确性已经在标注的回答里体现出来了。

正则化目标：用辅助数据，针对干扰和记忆污染这两类失效模式进行约束。

这三个目标通过任务加权采样器来平衡贡献，采用课程学习策略：训练早期偏向存储导向的数据，随着训练推进，逐步把采样权重转移到更难的长程任务和正则化数据上。

现在来看实验结果，这是验证方法有效性的关键部分。

实验在两类任务上评估：记忆操作任务和基于记忆的问答任务。

记忆操作任务用的是MemOps基准，专门评估记住、遗忘、更新这些操作的执行质量。有Full设置（模型收到完整的24轮对话作为输入）和Gold设置（只给模型真正相关的那几轮对话）。记忆问答任务用的是LoCoMo的黄金会话设置，以及NextMem数据集的上下文生成任务，后者包含SQuAD、HotpotQA、LoCoMo、LongMemEval四个数据集。

基线分四类：把完整信息拼入上下文的Qwen3.5骨干（4B、9B、27B）；在骨干上做RAG的版本；基于TTT思路的Temp-LoRA；以及参数化记忆模型Delta-Mem。

评估用GPT-4.1-mini做语言模型裁判，每个样本做三次独立评估取中位数。

Metis-4B在MemOps的Full设置上，平均得分达到76.5，超过了同等大小的Qwen3.5-4B全上下文版本的68.3，甚至超过了参数量大得多的Qwen3.5-27B全上下文版本的73.9。这个结果说明原生记忆并不只是在资源受限条件下的妥协方案，它在记忆操作质量上本身就有竞争力。

在NextMem的上下文生成任务上，Metis系列在多个数据集上明显优于RAG基线，也优于Temp-LoRA。Temp-LoRA在推理阶段需要对LoRA模块做梯度更新，效率代价较高，但效果仍然不如Metis的前向传播记忆更新。Delta-Mem采用低秩注意力修正的方式，也是参数化记忆的思路，但Metis的全矩阵记忆状态加上超记忆块的动态更新机制，总体性能更好。

消融实验给出了几个关键发现。去掉独立记忆查询投影，直接复用标准注意力查询，性能有明显下降，这验证了专用记忆查询对于减少跨步噪声的重要性。用普通线性更新替换GDN更新策略，性能也下降，说明门控增量更新机制对记忆状态的质量有实质性贡献。去掉重要性自适应选择，改为对所有位置均等处理，性能同样下降，说明选择性压缩是有效的，模型学会了从输入里挑出真正重要的信息来存储。去掉任何一个训练目标，性能都会下降，三个目标是互补的。

在行为分析方面，论文还做了一些定性分析。模型在处理显式记忆指令和隐式叙述时的性能差异不大，说明原生记忆程序确实能够从语义层面理解记忆意图，而不仅仅是响应关键词。在遗忘和更新操作上，Metis表现出明显的选择性：正确执行目标事实的遗忘或更新，同时保持其他无关事实不受影响。

论文作者对局限性也做了坦诚的讨论，这部分值得重点关注。

第一个局限性是长期任务性能衰减。固定大小的记忆矩阵M意味着存储容量有上限，随着交互轮数增加，信息压缩必然带来损失。当历史信息量远超M的容量时，模型就会出现信息丢失。这是当前架构的根本性约束，不是通过调参可以完全解决的。

第二个局限性是信息混淆。在某些情况下，模型会把相似实体的信息搞混，这可能是因为语义相近的内容在潜在空间里的表示彼此干扰。辅助数据的多实体绑定子集试图缓解这个问题，但没有完全解决。

这两个局限性其实指向了同一个深层问题：记忆矩阵是一个稠密混合的潜在表示，它把所有历史信息混合编码在一起，读取时很难完全干净地分离出特定信息。这和人类记忆的干扰效应有某种类似，但当前的架构还没有一个好的机制来结构化地组织M里的内容。

对做这个方向研究的人来说，这篇论文有几个具体可借鉴的点。

架构上，Fast Weight Programming的思路，也就是用超网络动态生成另一个网络的权重，结合注意力机制里的记忆读取，是实现参数化记忆的一条可行路径。独立记忆查询投影是一个简单但关键的设计，花一点额外参数换来噪声鲁棒性，值得在自己的设计里考虑。

数据上，论文的合成数据流程展示了如何用现有公开数据集构建多维度的记忆训练数据，三个维度、四种操作类型、两种指令显著性、两种噪声水平，这套设计框架本身就是可以复用的。辅助数据针对两种具体失效模式的定向构建，是一个很好的"对症下药"的数据工程思路。

训练上，课程学习从存储导向数据逐步过渡到更难任务的策略，以及冻结骨干只训练记忆参数的设置，都降低了训练难度和成本，是在有限资源下做记忆能力注入的实用方案。

更宏观地说，这篇论文的论点——外部能力可以通过有监督数据激活模型的内部能力，推理能力如此，记忆能力也应该如此——这个框架值得认真对待。记忆的特殊性在于它不只是一个过程，它还需要一个物理存储实体，所以不能像思维链那样纯粹靠训练数据就能激活，必须同时改造架构。但激活的路径是类似的：用精心设计的任务数据，让模型学会在自己的计算过程里执行正确的记忆行为。Metis是这条路上的第一步，它留下的最大开放问题是：如何让固定大小的记忆状态优雅地应对无限增长的历史，这是未来工作最值得突破的方向。
