# StateWeaver: Multi-Agent Coordination of Story-State Transitions for Long-Horizon Video Generation

> 有一个核心难题困扰着所有想用AI生成长视频的研究者：短视频生成模型的质量已经很好了，但把十几个、几十个镜头串成一个连贯故事，依然极其困难。角色换个景别就变了样，一个道具被用过之后下一个镜头还是原来的状态，事件引发的变化根本没有被后续画面继承

**摘要 (EN):** Modern video foundation models generate high-quality short clips, but preserving long-video consistency and correctly depicting event-driven state changes remain challenging. Existing agentic workflows face these challenges because continual planning and repair accumulate context, while reference updates remain limited. We introduce StateWeaver, which combines Active States and Hierarchical Collaboration to connect review-driven visual reference updates with cross-shot state inheritance. Active States translate state discrepancies identified during review into concrete visual asset requirements that guide reference construction, validation, and regeneration, preserving identity and already-correct content while repairing target attributes. Confirmed generation results are linked to the corresponding asset states, story time, and reference versions for verification and reuse by subsequent shots. Hierarchical Collaboration isolates execution contexts by task, clip, and repair round, and uses hierarchical memory to organize this process across multiple sets. Across multiple benchmarks, StateWeaver outperforms existing methods and produces long videos with sustained cross-shot consistency under predefined and autonomously planned storyboards.
