# Evaluating Large Language Models Trained on Code

> 今天我们要聊的这篇论文，关注的核心问题是如何准确评估大型语言模型在生成代码方面的能力。我们都知道，像GPT-3这样的大语言模型在处理自然语言任务上表现出色，但当它们被用来编写代码时，我们该如何判断它们写出的代码是否真的“好用”呢？这篇论文引

**摘要 (EN):** We introduce Codex, a GPT language model fine-tuned on publicly available code from GitHub, and study its Python code-writing capabilities. A distinct production version of Codex powers GitHub Copilot. On HumanEval, a new evaluation set we release to measure functional correctness for synthesizing programs from docstrings, our model solves 28.8% of the problems, while GPT-3 solves 0% and GPT-J solves 11.4%. Furthermore, we find that repeated sampling from the model is a surprisingly effective strategy for producing working solutions to difficult prompts. Using this method, we solve 70.2% of our problems with 100 samples per problem. Careful investigation of our model reveals its limitations, including difficulty with docstrings describing long chains of operations and with binding operations to variables. Finally, we discuss the potential broader impacts of deploying powerful code generation technologies, covering safety, security, and economics.
